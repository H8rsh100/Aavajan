# Changelog

All notable changes to Aavajan are documented here.

## [Unreleased]

- Tightened the loop to a four-second formation, five-second hold, and two-second dissolve with an immediate outward burst and no reset tail.

## [0.1.0] - 2026-09-25

### Added

- Rust terminal renderer with Unicode Braille sub-pixels and 24-bit ANSI color.
- Aavahan-to-Visarjan particle animation based on the supplied Ganesha artwork.
- Plain snapshot, bounded frame, deterministic seed, and headless benchmark modes.
- Offline PNG-to-mask extraction with a committed runtime mask.
- VHS and asciinema recording workflows.
- Regression tests, resize handling, CI, contribution guidance, and architecture documentation.
